Mastodon User Trends, Stats & Historical Growth

Continuous quantitative analysis tracking Mastodon user growth, daily active user retention, and historical network adoption across federated instances since September 2022.

📈

Mastodon User Growth

Tracking cumulative registered accounts across all federated Mastodon servers. The platform experienced monumental adoption surges during late 2022 and 2023, expanding from an open-source experiment into the foundation of the decentralized Fediverse.

👥

Daily & Monthly Active Users

Active users measure unique accounts active within rolling 30-day windows. Comparing daily active user retention against cumulative registrations computes the Engagement Ratio, revealing authentic long-term community participation.

⚡

Daily Net Change Velocity

Monitors day-over-day net user change volume (new account registrations minus deactivations). Trailing 7-day moving averages (7D MA) smooth transient weekend variations and API reporting delays to surface clear growth velocity trends.

Frequently Asked Questions // Mastodon User Stats & Trends

How many users does Mastodon have right now? ▼

Mastodon tracks over 10 million total registered accounts and between 1.0M and 1.5M monthly active users across thousands of independent servers. Live figures, day-over-day changes, and multi-year historical run-rates are updated daily on this dashboard.

What is the difference between total registered users and daily active users? ▼

Total Registered Users counts every account created across federated instances since launch. Active Users measures accounts that actively interacted, logged in, or posted within the trailing 30-day window, providing a realistic view of daily community activity.

How is Mastodon user growth velocity calculated? ▼

Daily velocity measures the net change between consecutive archive dates: Users(today) - Users(yesterday). Over custom ranges (1W, 1M, 6M, YTD, 1Y, 2Y, 3Y), the terminal calculates the daily run rate and plots trailing 7-day moving averages to isolate sustained momentum.

Where does this Mastodon statistics data come from? ▼

Data is ingested daily from the official Mastodon API statistics endpoint (https://api.joinmastodon.org/statistics) and preserved in this open-source repository with records starting in September 2022. You can download the filtered dataset anytime via the 📥 CSV export buttons.

Analytical Indicators & Velocity Modes

  • MAU Health Velocity (⚡ MAU Health - Primary): Day-over-day net active user expansion (+) and contraction (-) in the observed 30-day active population. Directly reveals platform health, community retention, and user churn.
  • Signups Velocity (👥 Signups - Secondary): Day-over-day net registered account creations and federated server additions. Useful for examining migration waves and viral signup surges.
  • Historical Signup Surges: One-click era shortcuts (Nov '22 Musk Wave, Jul '23 Threads Launch, Sep '24 Brazil X Ban) that allow instant inspection of peak user growth events.
  • 7-Day Moving Average (📈 7D MA): Trailing 7-observation arithmetic mean that filters transient weekend fluctuations and API reporting anomalies.
  • Engagement Ratio: Percentage of cumulative registered users active within the trailing 30 days (Active Users / Total Users).
